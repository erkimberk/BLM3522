## Proje Mimarisi

IoT Sensör (Python, simüle edilmiş) → MQTT → AWS IoT Core → AWS Kinesis Data Streams → AWS Lambda → AWS DynamoDB

## Proje Bileşenleri

1. **sensor_sim.py**: Sıcaklık ve nem verilerini simüle eden IoT sensörü
2. **lambda_function.py**: Kinesis'ten veri alan ve DynamoDB'ye yazan AWS Lambda fonksiyonu
3. **requirements.txt**: Python kütüphaneleri listesi
4. **AWS Yapılandırması**: IoT Core Thing'i, Kinesis, DynamoDB tablosu, Lambda rolü
